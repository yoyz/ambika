# Ambika Softsynth — Patch System

## Overview

The softsynth loads patches via the same 112-byte `Patch` struct used by
the original Ambika firmware (`common/patch.h`). Two sources are available:

1. **Built-in bank** — 208 patches converted from Shruthi-1 format
2. **External files** — Ambika .PRO files loaded at runtime

## Patch Data Structure

```cpp
struct Patch {
  OscillatorSettings osc[2];       // 8 bytes: shape, parameter, range, detune
  uint8_t mix_balance;             // 0-255
  uint8_t mix_op;                  // OP_SUM/SYNC/RING_MOD/XOR/FOLD/BITS
  uint8_t mix_parameter;
  uint8_t mix_sub_osc_shape;       // WAVEFORM_SUB_OSC_* enum
  uint8_t mix_sub_osc;             // 0-127
  uint8_t mix_noise;               // 0-127
  uint8_t mix_fuzz;                // 0-127 (pre-filter overdrive)
  uint8_t mix_crush;               // 0-255 (bit-crusher, +1 shifts)
  FilterSettings filter[2];        // 6 bytes: cutoff, resonance, mode (x2)
  int8_t filter_env;               // ENV_2 -> cutoff amount (-128..127)
  int8_t filter_lfo;               // LFO_2 -> cutoff amount (-128..127)
  EnvelopeLfoSettings env_lfo[3];  // 24 bytes: A,D,S,R + LFO shape,rate
  uint8_t voice_lfo_shape;         // LFO_4 waveform
  uint8_t voice_lfo_rate;          // LFO_4 rate (0-127)
  Modulation modulation[14];       // 42 bytes: source, destination, amount
  Modifier modifier[4];            // 12 bytes: op1, op2, op
  uint8_t padding[8];
};
```

Total: 112 bytes. All fields are byte-sized; the struct has no padding
and matches the on-disk format exactly.

## Built-in Patch Bank

**Files:** `patches.h`, `patches.cc`
**Generated by:** `tools/convert_patches.py`

208 patches converted from Shruthi-1 banks:
- `utils/shruthi_patches.txt` — 128 patches
- `utils/shruthi_patches_funkybank.txt` — 80 patches

```cpp
#include "patches.h"

// Access
voice.mutable_patch() = ambika::kPatches[index];
const char* name = ambika::kPatchNames[index];  // e.g. "junon  "
int count = ambika::kNumPatches;                // 208
```

The converter script handles all format differences:

### Oscillator Mapping
Shruthi-1 has 35+ algorithms; Ambika has 32. The converter maps
equivalent algorithms (CZ variants, wavetables, FM, vocal, noise)
and remaps CZ waveforms to Ambika's LP/PK/BP/HP variants.

### Modulation Remapping
Shruthi modulation sources/destinations use different enum values.
The converter translates all 12 modulation slots:
- Sources: ENV, LFO, VELOCITY, AFTERTOUCH, WHEEL, NOTE, NOISE, etc.
- Destinations: FILTER_CUTOFF, VCA, PITCH, PARAMETER, BALANCE, etc.
- Unavailable destinations (CV outputs, trigger inputs) → no-op
- Attack modulation polarity inverted (Shruthi→Ambika)

### Mix Operator Mapping
| Shruthi | Ambika |
|---------|--------|
| OP_SUM | OP_SUM |
| OP_SYNC | OP_SYNC |
| OP_RING_MOD | OP_RING_MOD |
| OP_XOR | OP_XOR |
| OP_FUZZ | OP_SUM + mix_fuzz |
| OP_CRUSH_4/8 | OP_SUM + mix_crush |
| OP_FOLD | OP_FOLD |
| OP_BITS | OP_BITS |
| OP_DUO | OP_SUM |
| OP_PING_PONG_* | OP_SUM |

### Regenerating the Bank
To regenerate with custom patches:

```bash
cd softsynth
python3 tools/convert_patches.py ../utils .
make clean && make
```

## External Patch Files (.PRO)

The original Ambika stores programs as RIFF-based .PRO files on SD card.
The format is:

```
RIFF <size> MBKS
  name <16> <name\0 + padding>
  obj  <size> <type=1> <112-byte Patch>
  obj  <size> <type=5> <84-byte Part data>
```

To load from a .PRO file:

```cpp
#include "common/patch.h"

bool LoadProgram(const char* path, ambika::Patch* patch, char* name_out) {
  FILE* f = fopen(path, "rb");
  if (!f) return false;

  // Read RIFF header
  char hdr[12];
  if (fread(hdr, 1, 12, f) != 12 || memcmp(hdr, "RIFF", 4)) { fclose(f); return false; }

  // Walk chunks
  while (true) {
    char id[4]; uint32_t sz;
    if (fread(id, 1, 4, f) != 4) break;
    if (fread(&sz, 4, 1, f) != 1) break;

    if (!memcmp(id, "name", 4)) {
      char buf[16];
      fread(buf, 1, sz < 16 ? sz : 16, f);
      if (name_out) memcpy(name_out, buf, 16);
      fseek(f, sz > 16 ? sz - 16 : sz > 16 ? 0 : 0, SEEK_CUR);
    } else if (!memcmp(id, "obj ", 4)) {
      uint32_t type;
      fread(&type, 4, 1, f);
      if (type == 1 && sz >= 4 + 112) {
        fread(patch, 1, 112, f);
        fclose(f);
        return true;
      }
      fseek(f, sz - 4, SEEK_CUR);
    } else {
      fseek(f, sz, SEEK_CUR);
    }
  }
  fclose(f);
  return false;
}
```

Usage:
```cpp
ambika::Patch patch;
char name[17] = {0};
if (LoadProgram("patches/001.PRO", &patch, name)) {
  voice.mutable_patch() = patch;
  printf("Loaded: %s\n", name);
}
```

## Creating New Patches

Patches can be created programmatically by filling a `Patch` struct,
loaded from .PRO files via the RIFF parser above, or converted from
Shruthi-1 SYX files using the toolchain:

```
Shruthi .syx → convert_shruthi_syx.py → .txt → convert_patches.py → C++
```
